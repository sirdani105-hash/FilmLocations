# Lugares de Rodaje en San Francisco 🎬

Repositorio creado para practicar consultas y gestión de bases de datos utilizando **SQL**. Contiene información y registros sobre locaciones y filmaciones en la ciudad de San Francisco.

---

## 📁 Estructura del Proyecto

* `Localizaciones de rodaje en San Francisco...sql` (o el nombre de tu archivo): Archivo principal que contiene el script de creación de la base de datos, tablas y la inserción de datos (SQL dump).

---

## ⚙️ Cómo usar este repositorio

1. Clona el repositorio o descarga el archivo de la base de datos en tu computadora.
2. Abre tu gestor de base de datos favorito (como MySQL Workbench, DBeaver, PostgreSQL, etc.).
3. Importa el archivo `.sql` para recrear las tablas y cargar los datos de prueba.
4. ¡Empieza a practicar tus consultas SQL!
